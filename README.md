# Quentin Juarez

Full-stack developer. Vue.js, Nuxt, Node.js, TypeScript.

Portfolio: **[www.quentinjuarez.dev](https://www.quentinjuarez.dev/)**

## Projects

- **[Bikes Map](https://bikes.quentinjuarez.dev)**: every Paris shared bike and
  scooter on one live map. Lime, Voi, Dott and Vélib in real time, nearest ride
  first. Nuxt, Leaflet, GBFS API.
- **[Overtime](https://overtime.quentinjuarez.dev)**: predict Rocket League
  esports scores, earn points, climb private leaderboards with friends. Vue.js,
  Vite, PWA.
- **[Encore](https://encore.quentinjuarez.dev)**: turn the setlist of a concert
  you went to into a Spotify playlist, song for song. Nuxt, Spotify API,
  setlist.fm API.
- **[La Roue de la Chance](https://roue.quentinjuarez.dev)**: French
  Wheel-of-Fortune word game. Ranked 1v1 with an ELO ladder, private rooms,
  local pass-and-play. Nuxt, realtime, server-authoritative.
- **[Faraway](https://faraway.quentinjuarez.dev)**: guess a historical figure
  from two pins on a world map, where they were born and where they died. Nuxt,
  D3.js.

## Packages

- **[vue3-router-middlewares](https://www.npmjs.com/package/vue3-router-middlewares)**:
  attach middleware functions to Vue Router navigation through route meta
  fields, inherited from parent routes. Vue 3, Vue Router 4 and 5, TypeScript.
  `yarn add vue3-router-middlewares`
- **[tailwindcss-custom-colors](https://www.npmjs.com/package/tailwindcss-custom-colors)**:
  one hex color in, a full Tailwind shade scale from 50 to 950 out, plus the CSS
  variables and an automatic readable contrast color. TypeScript.
  `yarn add tailwindcss-custom-colors`
- **[vite-plugin-global-types](https://www.npmjs.com/package/vite-plugin-global-types)**:
  collects your exported types into a generated `global.d.ts`, so you can use
  them without importing them. Vite 5 to 8, TypeScript.
  `yarn add -D vite-plugin-global-types`
- **[oxlint-tailwindcss-vue](https://www.npmjs.com/package/oxlint-tailwindcss-vue)**:
  run your oxlint-tailwindcss rules on the Tailwind CSS classes in Vue
  templates, without ESLint. Oxlint, Vue 3, TypeScript.
  `yarn add -D oxlint-tailwindcss-vue`
